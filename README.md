# upbolt.github.io

Contains various showcases/utilities that run completely client-side in the browser

https://upbolt.github.io/leptos_gltf_viewer - Bindful renderer written in Rust with the ability to import `.glb` files to display

https://upbolt.github.io/leptos_primitives - UI component library for the `leptos` web framework in Rust

https://upbolt.github.io/text-gradient-animated - Combine colors of your choosing into an infinitely animated text gradient (there apparently is no functioning page that works this way that i could find, so i had to resort to creating my own 💔)
